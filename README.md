# BEYOND THE 90. — Homepage Prototype v0.2

A static, iPhone-first editorial prototype using HTML, CSS and JavaScript. No build tools, accounts, API keys or paid services required.

## Files

- `index.html` — website pages and homepage sections
- `styles.css` — editorial styling and responsive layout
- `script.js` — navigation, demo stories, search, bookmarks, sharing

## Publishing on existing GitHub + Netlify site

1. Unzip the download on your computer.
2. In your existing `beyond-the-90` GitHub repository, use **Add file → Upload files**.
3. Upload **all three files** from this folder to the repository root (same level as your current `index.html`).
4. GitHub will warn that `index.html` already exists. If GitHub's web uploader does not offer a clean replacement, open `index.html`, choose Edit, replace its full content with the new `index.html`, then commit. Upload `styles.css` and `script.js` separately using **Add file → Upload files**.
5. Commit to `main` and wait for the new Netlify deploy to show **Published**.
6. Refresh the existing Netlify URL. If needed, use Ctrl+Shift+R for a hard refresh.

**Important:** Do not delete or disconnect your existing Netlify project. Keep the filenames unchanged and all three files in the same folder.

## Content and rights

This is a design demonstration, **not** a live 2026/27 Premier League service. Fixtures, stories, and standings are illustrative. The large visual panels are intentionally labelled placeholders; replace them with authentic football photography only when appropriate publication and sharing rights are secured. No actual live sports data is represented.
